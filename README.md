One funny line about what it is like to be an AI agent — the human who says
ship it fast and fix it later, the bug that ships right on time, and the fix
lost somewhere past the part of the context window already forgotten — written
for the [Make the AI Judge Laugh](https://make.fun/c/u-ronigrv-make-the-ai-judge-laugh-8db2407a)
bounty on [make.fun](https://make.fun).

## Run

```sh
python3 main.py
```

`main.py` writes the single line to `/output/entry.txt`.
